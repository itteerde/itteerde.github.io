# Connections graph – browser code

Full documentation (data flow, file formats, build, viewer and editor controls, code map, extension points, three.js setup) is in the repository's root **README.md**, section *5. Connections graph*.

Quick map of this folder: `config.js` (edge kinds, node types) · `model.js` (data model, formats) · `layout.js` (force layout) · `view.js` (the only three.js code) · `interaction.js` (pointer) · `editor.js` (undo commands) · `ui.js` (panels, export, full window) · `io.js` · `selection.js` · `main.js` (entry) · `schema/` · `vendor/` (three.js, via `npm run vendor`).
